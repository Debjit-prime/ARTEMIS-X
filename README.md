# 🚀 Project Artemis-X: Interactive Lunar Base Digital Twin

**A 3D WebGL simulation of a sustainable lunar South Pole architecture, designed for the National Space Day Lunar Base Design Challenge.**

## 📌 Project Overview
Project Artemis-X is an interactive digital twin of a proposed lunar habitat at Shackleton Crater. It visualizes a strict zero-waste, closed-loop ecosystem utilizing In-Situ Resource Utilization (ISRU). This project was rapidly prototyped to demonstrate how advanced systems engineering constraints can be translated into an interactive, high-fidelity 3D environment.

## 🛠️ Technology Stack
*   **Core:** HTML5, CSS3, Vanilla JavaScript
*   **3D Rendering:** Three.js (r128)
*   **Camera Controls:** OrbitControls.js

## ✨ Key Interactive Features
*   **Real-Time 3D Rendering:** Fully interactive WebGL scene with orbital rotation, zooming, and auto-idle camera panning.
*   **Advanced Lighting & PBR:** High-contrast lunar lighting models with Physically Based Rendering (PBR) materials, featuring custom Tiranga (Saffron, White, Green) architectural accents.
*   **Procedural Terrain:** Dynamically generated lunar regolith with a custom crater field and vertex-colored albedo variations.
*   **Dynamic UI HUD:** An integrated aerospace-style dashboard featuring a live system clock and modular data panels explaining the base's Energy, Water, Oxygen, and Communication systems.
*   **Atmospheric Effects:** Multi-layered twinkling starfield, residual engine heat glow, and animated exhaust plumes.

## 🧠 Methodology & AI Orchestration
**Role:** Chief Systems Engineer & Concept Designer | **Author:** Debjit Dutta

This project was built to explore the limits of rapid ideation and AI-assisted development. While the conceptual architecture and system requirements (such as Molten Regolith Electrolysis and Aeroponics) were manually defined, the underlying Three.js code and UI structure were generated using advanced AI models. 

My primary focus was on **AI Orchestration and Prompt Engineering**:
1. Translating strict aerospace design constraints into programmatic prompts.
2. Managing the integration of multiple complex geometries (Starship, Solar Towers, Kevlar Domes, Rovers).
3. Debugging and refining the generated JavaScript to ensure a seamless, performant browser experience.

## 🚀 How to Run Locally
Because this project uses standard web technologies without a build step, it is entirely self-contained:
1. Clone or download this repository.
2. Ensure you have an active internet connection (required to fetch the Three.js CDN libraries).
3. Open the `index.html` file directly in any modern web browser (Chrome, Edge, Safari, Firefox).
